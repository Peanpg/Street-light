# เว็บสำรวจมิเตอร์ไฟสาธารณะ น้ำพอง

ข้อมูล 22 หม้อแปลงจากชีตแรก “ตำแหน่งหม้อแปลง” ในไฟล์ตำแหน่งหม้อแปลง.xlsx เท่านั้น แบ่งเป็น 9 ตำบลโดยเทียบรหัส PEA และพิกัดกับข้อมูลเดิม มี 6 ฟีดเดอร์ กำลังรวม 1,690 kVA จำนวนผู้ใช้ไฟรวม 1,434 ราย

## การใช้งาน

- เปิดเว็บได้โดยไม่ต้องกรอกรหัสทีม กรอกชื่อผู้สำรวจก่อนบันทึก
- ค้นหาชื่อ Location หรือ PEA และเลือกตำบล/สถานะ
- แตะหมุดหรือรายการเพื่อดู PEA, kVA, ผู้ใช้ไฟ, รหัสเฟส, เจ้าของ, Lat และ Long
- กดตำแหน่งของฉันแล้วอนุญาต GPS บนมือถือ กดปุ่มจะเลื่อนแผนที่ไปหาคุณโดยคงระดับซูมเดิม การอัปเดต GPS ต่อไปจะขยับเฉพาะหมุด
- ปุ่มกรอบสี่เหลี่ยมรูปเป้าข้าง “ตำแหน่งของฉัน” เป็นปุ่มเปิด/ปิดเลื่อนตาม GPS กดเปิดจะซูมไปตัวเองครั้งเดียวแล้วเลื่อนตามพิกัดใหม่โดยคงระดับซูม ปุ่มเป็นสีเข้มขณะเปิด กดอีกครั้งหยุดเลื่อนตามแต่หมุดและการส่งตำแหน่งยังทำงาน
- กดตำแหน่งของฉันเพื่ออ่าน GPS แล้วกรอกชื่อทีมและกดยืนยันในแถบ “ทีมออนไลน์” จึงเริ่มแสดงตำแหน่งให้ทีม ไม่มีปุ่มหยุดแชร์ เมื่อปิด GPS หรือหน้าเว็บหยุดส่งพิกัด หมุดจะหมดอายุ 90 วินาทีหลังอัปเดตล่าสุด หมุดทีมเป็นสีม่วงพร้อมชื่อ ส่งพิกัดทุก 10 วินาทีเมื่อเปิดหน้าแผนที่และ GPS ยังใหม่ ผู้อื่นโหลดทุก 5 วินาที ตำแหน่งหายหลังไม่มีข้อมูลใหม่ 90 วินาที การปิดหน้า/พักแอปอาจหยุด GPS จึงต้องเปิดหน้าแผนที่ไว้ระหว่างใช้งาน
- บันทึก แก้ไข และลบผลสำรวจโดยมีหน้าต่างยืนยันลบ จุดหม้อแปลงยังอยู่
- ช่องผู้สำรวจของงานใหม่เติมชื่อทีมที่ยืนยันไว้โดยอัตโนมัติและแก้ไขเองได้ ชื่อที่แก้เองจะไม่ถูกเขียนทับเมื่อเปลี่ยนชื่อทีม จุดที่มีผลบันทึกแล้วแสดงชื่อผู้สำรวจเดิม
- รายงานแยกตำบล แตะรายการเพื่อกลับไปที่หมุด และดาวน์โหลด CSV
- โหลดสถานะส่วนกลางทุก 5 วินาทีเมื่อเปิดหน้าใช้งาน ข้อมูลที่บันทึกพร้อมกันจะตรวจ revision ในฐานข้อมูล ถ้ามีคนแก้ไขก่อนจะให้โหลดข้อมูลล่าสุด

เติมตำบลครบ 22 จุดโดยเทียบรหัส PEA และพิกัดตรงกับข้อมูลสำรวจเดิม 351 จุด ใช้ตำบลเป็นตัวกรองหลักและเก็บฟีดเดอร์ในรายละเอียด รหัสเฟสและเจ้าของแสดงตามต้นฉบับ จุด 64-021639 มี Location เป็น “-” จึงแสดงว่าไม่ระบุ Location

## อัปโหลด GitHub แล้ว Deploy Vercel

1. แตก ZIP นี้
2. สร้าง repository ใหม่ เช่น transformer-survey แนะนำแยกจาก Street-light เพื่อรักษางานเดิม
3. ใน GitHub กด Add file → Upload files แล้วอัปโหลดไฟล์และโฟลเดอร์ข้างในทั้งหมด ให้ package.json และโฟลเดอร์ app อยู่ที่ราก repository ไม่ต้องอัปโหลด ZIP
4. ใน Vercel กด Add New → Project → Import repository ใหม่
5. เลือก Framework Preset เป็น Next.js, Root Directory เป็นราก repository, Build Command และ Output Directory ใช้ค่าอัตโนมัติ
6. ไป Storage → Create Database → Neon สร้างและเชื่อมกับ project นี้ หรือเชื่อม Neon เดิมที่มีอยู่ เลือก Production และ Preview
7. ตรวจ Environment Variables ว่ามี DATABASE_URL แล้ว หากสร้างเองให้ใช้ connection string จาก Neon ห้ามใส่ไว้ใน GitHub
8. กด Deploy หากเชื่อมฐานข้อมูลหลัง deploy แล้ว ให้ไป Deployments → deployment ล่าสุด → Redeploy
9. รอ Ready แล้วกด Visit

ตาราง transformer_survey_status จะสร้างอัตโนมัติเมื่อโหลดสถานะครั้งแรก จึงใช้ Neon เดิมร่วมกับเว็บโคมไฟได้โดยแยกผลสำรวจคนละตาราง ไม่ต้องรัน schema.sql เองเว้นแต่ต้องการสร้างด้วย SQL editor

ตาราง meter_team_locations สำหรับพิกัดทีมจะสร้างอัตโนมัติเมื่อเปิดแผนที่หลังเชื่อมฐานข้อมูล ผู้ใช้ต้องอนุญาตตำแหน่งบน HTTPS ของ Vercel และยืนยันชื่อทีมก่อนส่งพิกัด

กรณีไม่มี DATABASE_URL แผนที่จะยังแสดงข้อมูลต้นทาง แต่การบันทึกส่วนกลางจะปิดและบอกให้ตั้งค่า DATABASE_URL แล้ว Redeploy

ทุกคนที่มีลิงก์เปิดดูและบันทึก/แก้ไข/ลบผลสำรวจได้ เพราะใช้รูปแบบไม่มีรหัสตามที่กำหนด

## ทดสอบหลัง deploy

เปิด 2 เครื่อง บันทึกหนึ่งจุดแล้วดูอีกเครื่องภายใน 5 วินาที ลองแก้ไขจุดเดียวกันจากทั้ง 2 เครื่อง เครื่องที่ใช้ข้อมูลเก่าต้องได้รับข้อความให้โหลดข้อมูลล่าสุดก่อน ตรวจลบผลสำรวจแล้วจุดกลับเป็นยังไม่สำรวจ และลองกดรายการในหน้ารายงานให้แผนที่ไปหาหมุด

## รันในเครื่อง

ใช้ Node.js 22.13 ขึ้นไป ติดตั้งด้วย npm ci คัดลอก .env.example เป็น .env.local แล้วใส่ DATABASE_URL จากนั้น npm run dev สำหรับพัฒนา หรือ npm run build และ npm start สำหรับ production

ข้อมูลต้นทางอยู่ app/transformers.json พิกัด x ของ Excel คือ Long และ y คือ Lat ไฟล์นี้เก็บข้อมูลต้นฉบับทั้ง 9 ช่องโดยปรับชื่อ field สำหรับเว็บและตัดช่องว่างหัวท้าย Location
